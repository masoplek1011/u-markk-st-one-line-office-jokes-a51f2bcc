## The joke

> The office coffee machine has flashed DESCALE since March, so today it took revenge the only way it could: decaf.

Every office has that one machine everyone ignores — the warning light blinking for months, nobody quite owning the fix — until the machine quietly files its own grievance. The laugh lands on the last word: the pettiest revenge a coffee machine can take is serving you decaf.

## How it works

`main.ts` (Node 22, standard library only) writes the single joke line — no trailing newline — to `entry.txt` inside the directory given by `MAKEFUN_OUTPUT_DIR` (defaults to `/output`). It is fully deterministic: same input, same output, every run.
